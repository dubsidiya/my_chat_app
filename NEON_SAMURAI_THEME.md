# Neon Samurai Theme — Инструкция по активации

## Что добавлено

Добавлена новая тема **Neon Samurai** — зимняя ночь с фиолетовым неоном.

### Палитра цветов

- **Фон**: Тёмно-синий почти чёрный (#0A0D12, #0F1419) — как ночное небо перед снегом
- **Акцент**: Фиолетовый неон (#8B5CF6, #A78BFA) — единственное тепло
- **Текст**: Холодные серые (#E5E7EB, #9CA3AF) — металл меча, лёд
- **Границы**: Минималистичные, тонкие (#1A1F26)

### Вайб

Холодная зимняя ночь в японском киберпанк-городе — минималистично, сдержанно, с неоновыми акцентами как вывески на улицах Токио. Самурай в ночном городе с фиолетовым свечением катаны.

## Как активировать

### Способ 1: Через настройки в приложении

1. Откройте приложение
2. Перейдите в **Профиль** (аватар в левом верхнем углу)
3. Найдите раздел **Тема оформления**
4. Выберите **Neon Samurai**

### Способ 2: Установить по умолчанию (для разработчиков)

Откройте `lib/theme/theme_variant.dart` и измените значение по умолчанию:

```dart
AppThemeVariant appThemeVariantFromStorage(String? raw) {
  if (raw == null || raw.isEmpty) return AppThemeVariant.neonSamurai; // ← измените здесь
  // ...
}
```

Или в `lib/theme/app_colors.dart`:

```dart
static AppThemeVariant _activeVariant = AppThemeVariant.neonSamurai; // ← измените здесь
```

## Файлы, которые были изменены

- `lib/theme/app_colors.dart` — добавлена палитра `_paletteNeonSamurai`
- `lib/theme/theme_variant.dart` — добавлен enum вариант `neonSamurai`

## Что дальше

Тема автоматически применится ко всем экранам приложения через существующую систему тем. Все компоненты (кнопки, карточки, поля ввода, диалоги) будут использовать новую палитру.

### Особенности темы

- **Статус онлайн**: Фиолетовая точка с анимацией pulse
- **Непрочитанные сообщения**: Фиолетовые бейджи с box-shadow glow
- **Поиск и инпуты**: Фиолетовая подсветка при фокусе
- **Границы**: Едва заметные, деликатные
- **Scrollbar**: Фиолетовый оттенок
- **Иконка шифрования**: Светящаяся фиолетовая точка
