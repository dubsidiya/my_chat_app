Политика конфиденциальности Reollity

Дата обновления: 14 сентября 2026.

1. Какие данные обрабатываются

  • логин (или email) и пароль для входа (пароль хранится в виде хеша);
  • отображаемое имя и фото профиля, если вы их указываете;
  • текст сообщений, голосовые сообщения, фото, видео и файлы в чатах;
  • данные звонков (факт звонка, участники, служебная информация соединения);
  • токен устройства для push-уведомлений (Apple Push Notification service и Firebase Cloud Messaging), если вы разрешили уведомления;
  • IP-адрес в журналах безопасности (защита от злоупотреблений);
  • для преподавателей — данные учеников, которые вы сами вносите: имя, телефон, email родителя, заметки, занятия, оплаты и загруженные выписки.

2. Зачем это нужно

Данные используются только для работы сервиса: вход, доставка сообщений, звонки, уведомления, учёт занятий. Мы не продаём данные и не используем их для рекламного трекинга.

3. Где хранятся данные

Сервер приложения (хостинг в Yandex Cloud) и файловое хранилище Yandex Object Storage. Push-уведомления доставляются через Apple Push Notification service и Firebase Cloud Messaging.

4. Шифрование чата

Сообщения шифруются на устройстве алгоритмом AES-256-GCM. Ключ чата хранится на сервере и выдаётся участникам чата. Это защита содержимого при хранении и передаче, но не гарантия, что сервер не может прочитать переписку. В push-уведомлении может быть короткое превью сообщения.

5. Удаление аккаунта

Удалить аккаунт можно в приложении: Профиль → Удалить аккаунт. Логин, профиль, сообщения и чаты удаляются. Если есть записи учёта занятий и оплат, они сохраняются без ваших персональных данных (имя входа заменяется служебным идентификатором), чтобы не ломать финансовый учёт.

6. Дети

Приложение не предназначено для детей младше 13 лет. Преподаватель может хранить данные своих учеников, в том числе несовершеннолетних, как третьих лиц.
